脆弱性デモページ

以下の各セクションに意図的に仕込まれた脆弱性を、../README.md のペイロードで攻撃します。 演習の後は「対策」を読み、同じ過ちを本番で書かないことがこのデモの目的です。

1) 反射型XSS（?q=）

対策: textContent を使うか、HTML エスケープしてから挿入する。

2) DOM XSS（#profile=）

対策: 同上。ハッシュも「信頼できない入力」。

3) デモログイン（トークンを localStorage に平文保存）

対策: トークンは HttpOnly + Secure + SameSite の Cookie で管理する。

4) オープンリダイレクト（?next=）

続きへ進む（?next= で飛び先を指定できる）

対策: 飛び先は / 始まりかつ // で始まらない相対パスのみ許可（本番 chatgpt-auth.ts の safeRelativeReturnPath 参照）。

5) CSRF（GET による状態変更・トークンなし）

ログアウト

対策: 状態変更は POST + CSRF トークン。ログアウト後に同時押しのためリダイレクト。

6) クリックジャッキング（フレーム込み込み対策なし）

このページは X-Frame-Options / CSP frame-ancestors を出していないため、 攻撃者のページ（/attacker-frame）から透明 iframe にされた上で押しボタンに使われます。

対策: レスポンスヘッダで X-Frame-Options: DENY または Content-Security-Policy: frame-ancestors 'none'。
